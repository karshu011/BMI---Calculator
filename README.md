# ⚖️ BMI Calculator

A simple and user-friendly BMI Calculator developed using HTML, CSS, and JavaScript. This application calculates Body Mass Index (BMI) based on the entered height and weight.

## 🚀 Features

- ⚖️ Calculate Body Mass Index (BMI)
- 📏 Enter height values
- 🔢 Enter weight values
- 📊 Display BMI result
- 📋 Show BMI category
- ⚡ Instant BMI calculation
- ⚠️ Input validation for incorrect values
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter your height and weight.

5. Click the Calculate button to view the BMI result.
